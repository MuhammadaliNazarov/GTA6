# Team sync — every five minutes

Use the GitHub issue **[SYNC] One-hour demo live log** as the shared team chat. Pin it. Ali, Rioja, Yüin, and Olenem post at minutes 05, 10, 15, 20, 25, 30, 35, 40, 45, 50, and 55.

## Required comment

```md
### [HH:MM] Name — green / yellow / red
Done: <one concrete result or commit>
Now: <one thing in progress>
Need: <specific decision, file, or help; write “none” if clear>
Proof: <commit, screenshot, room URL, or test result>
```

## Rules

1. Read the other three updates before posting yours.
2. If blocked for more than two minutes, post **red** and tag the person who can unblock you.
3. Before editing shared integration code, state the file and reason in the sync issue.
4. Ali resolves conflicts and applies the cut rules in [demo-task-board.md](demo-task-board.md).
5. At minute 55, post final proof and the one known limitation.

## Labels

Use: `role:ali`, `role:rioja`, `role:yuin`, `role:olenem`, `status:blocked`, `status:ready`, and `demo-critical`.

Public viewers can follow progress. Add contributors through **Settings → Collaborators** once you have their GitHub email or username; only collaborators should commit or comment.
