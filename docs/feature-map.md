# Feature map

| What Ali wants | First-demo interpretation | Owner | Proof |
| --- | --- | --- | --- |
| A game people can play in a browser or locally | Browser-first web build with a local dev command | Ali | Two browsers load the game |
| People join and fight like a multiplayer arena | Two-player room by code, movement and health sync | Yüin | Both players see each other move and take damage |
| A 3D GTA-like setting | One original, compact city-block arena | Olenem | Walkable arena with collision and landmarks |
| Everyone can summon tools | Curated summon wheel: Pulse, Cat Swarm, Grapple | Rioja | Each summon has a visible, repeatable effect |
| The game should be ready to demonstrate in an hour | One room, two players, one victory condition | Whole team | Recorded two-player round |

## Explicitly out of scope today

- GTA, Fortnite, or other third-party IP assets.
- Persistent accounts, voice recognition, matchmaking, mobile, an open world,
  user-generated arbitrary assets, and large-scale hosting.
